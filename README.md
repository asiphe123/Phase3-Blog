#My Blog post application in Next.js 

Supports Markdown-driven posts using SSG, NextAuth.js authentication, and protected comment submission for logged-in users.
---
# Features

- Write blog posts in Markdown 
- Static Site Generation (SSG) for fast and SEO-friendly pages  
- Email and password authentication using NextAuth.js  
- Comment system restricted to logged-in users  
- Responsive design with Tailwind CSS  
- Dynamic routing for individual blog posts
